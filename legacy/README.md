## 🚀 Deployment

This portfolio is deployed via **GitHub Pages**.

**Live URL:** `https://masudul2002.github.io`

### Run Locally

```bash
# Clone the repository
git clone https://github.com/masudul2002/masudul2002.github.io.git

# Navigate to the project folder
cd masudul2002.github.io

# Open in browser
start index.html
```

> No build step required — it's pure HTML, CSS & JavaScript!
